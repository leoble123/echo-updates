# Echo Server

Echo Server is the BlueBubbles server (https://github.com/BlueBubblesApp/bluebubbles-server,
Apache License 2.0, by the BlueBubbles Development Team) reworked as the engine
for Echo: lean enough for an 8 GB Mac, watching and healing itself, and with
Echo's own features built in. BlueBubbles' licence and copyright notices are
kept as they are (LICENSE); changes are listed in this branch's history.

Built by `.github/workflows/build.yml` on GitHub's Apple Silicon machines.
